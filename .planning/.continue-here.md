## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Next.js Request Body Cloning | Cloning Request objects using `new Request(url, req)` for POST requests causes body stream ingestion failures in Next.js production builds. | blocking | Use a JS Proxy on `req` to intercept and clean the `url` property getter without touching the body stream. |
| Keystatic Directory Deletions | Keystatic attempts to clean up empty asset folders by calling `fs.rm(dirPath)` flatly, causing Node.js `EISDIR` errors. | blocking | Intercept the `/update` POST payload and remove directory paths from the `deletions` array before forwarding to Keystatic. |

<current_state>
We are resolving a conflict between Next.js dynamic routing and flat blog post images. When a blog post references a flat image link like `/blog/image.png`, Next.js's dynamic `/blog/[slug]` route intercepts it as a blog post slug and fails, returning HTML instead of the image. Moving assets to a separate public subfolder (e.g. `/blog-images/`) and updating links bypasses this dynamic route segment.
</current_state>
